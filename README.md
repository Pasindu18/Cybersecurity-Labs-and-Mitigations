Hands-on implementation of application security mitigations, network packet analysis, and secure configurations.
Welcome to my cybersecurity engineering portfolio. This repository serves as a centralized hub documenting my hands-on implementation, threat mitigation strategies, and risk assessment frameworks developed during my postgraduate studies.

My approach bridges deep technical analysis with enterprise risk compliance to build secure, resilient digital infrastructures.

## 📂 Repository Structure & Navigation

Click on the links below to navigate through the specific domains of my practical work:

### 📁 [01-Software-Security-Labs](./01-Software-Security-Labs/)
Focused on secure coding practices, application vulnerability identification, and source code hardening.
* **Key Implementation:** Mitigated **Stored & Reflected Cross-Site Scripting (XSS)** flaws within a Java Maven web environment deployed on Apache Tomcat using the **OWASP Java Encoder** library.
* **Core Tools:** OWASP ZAP, Apache Tomcat, Maven.

### 📁 [02-Network-Security-Labs](./02-Network-Security-Labs/)
Focused on perimeter hardening, deep packet inspection, and real-time network visibility.
* **Key Implementation:** Executed stateful **TCP 3-Way Handshake** and **DNS query infrastructure analysis** to build baselines for anomaly detection. Configured Layer 2 **Port Security** (Sticky MAC addresses and Shutdown violation states) on enterprise switch ports.
* **Core Tools:** Wireshark, Cisco Packet Tracer.

### 📁 [03-Audit-and-Risk-Management](./03-Audit-and-Risk-Management/)
Focused on governance, regulatory compliance, and aligning technical controls with enterprise frameworks.
* **Key Implementation:** Developing structural security audit checklists, executing vulnerability assessments, and formulating risk remediation blueprints aligned with industry standards like **ISO/IEC 27001** and **NIST**.
